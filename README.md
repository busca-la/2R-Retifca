# Rectificadora de Motores 2R

Sitio institucional en español construido con React y Vite.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Publicación

```bash
npm run build
```

Directorio de salida: `dist`.

## Configuración de contacto

Crear un archivo `.env` a partir de `.env.example` y completar solamente los datos verificados de la empresa. Los números de WhatsApp deben llevar código de país, sin símbolos ni espacios. Si no hay número configurado, el formulario permite copiar una consulta; no simula el envío.

## Contenidos

Los textos de servicios describen categorías generales de rectificación; deben ser confirmados con la empresa antes de la publicación definitiva. Las fotografías son ilustrativas y proceden de Unsplash; no representan necesariamente el taller 2R. Las marcas citadas pertenecen a sus titulares y no implican vínculo oficial.

## Identidad

El isotipo vectorial del sitio es una interpretación provisional inspirada en los colores del material compartido. Reemplazar por el logotipo original en SVG/PNG transparente cuando esté disponible.
